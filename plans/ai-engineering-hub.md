# Plan: ai-engineering-hub

> Generated by the planner from `prds/ai-engineering-hub.md`. Thick end-to-end phases;
> all phases ship in one PR.

## Architectural decisions

- Stack: Vite 5 + React 18 + TypeScript (strict mode). No substitution — PRD is explicit.
- Styling: Tailwind CSS v3 with theme extension for the deep indigo/violet accent (tailwind indigo-600/700 base, extended to brand-600/700/800 tokens). No external animation libraries; CSS transitions only.
- Routing: React Router v6 with BrowserRouter + Routes. Four routes: / (Home), /pivot, /ai-native-coding, /about. Hash-based anchor scroll (#tracks) for the hero CTA so it works without JS scroll-to-ref juggling.
- Testing: Vitest + @testing-library/react + @testing-library/jest-dom + jsdom environment. Single test file covering all required assertions. vitest.config.ts mirrors tsconfig.
- Component structure: src/components/ (Nav, Footer, TrackCard), src/pages/ (Home, PivotTrack, AINativeCoding, About), src/data/tracks.ts (typed track manifest). The tracks.ts data file is the extensibility seam — adding a third track later is a data change, not a structural rewrite.
- Layout: a persistent Layout component (Nav + Footer) wraps all route outlets. Max content width 1200px centered (max-w-7xl mx-auto px-4). Viewport meta and Tailwind sm:/md:/lg: breakpoints ensure mobile-first responsiveness.
- Build gate: tsc --noEmit must pass with zero errors before vite build. Both are chained in the build script.
- The PRD is firmly static/no-backend — no fetch calls, no env vars, no external APIs anywhere in V1.

## Phase 1: Phase 1 — Project Scaffold, Routing Shell, and Nav/Footer

### What to build

Bootstrap the entire project from scratch. Run `npm create vite@latest` (or equivalent) to generate the Vite+React+TS template, then install and wire Tailwind CSS v3 (postcss + autoprefixer), React Router v6, and the full Vitest/RTL dev-dependency tree (@testing-library/react, @testing-library/jest-dom, @testing-library/user-event, jsdom, vitest). Configure tailwind.config.ts with a custom `brand` color palette (deep indigo/violet: brand-600 #4f46e5, brand-700 #4338ca, brand-800 #3730a3), Inter via @fontsource/inter or system font stack, and the content glob covering src/. Add a vitest.config.ts with the jsdom environment and a globals: true setup file that imports @testing-library/jest-dom. Wire package.json scripts: dev (vite), build (tsc --noEmit && vite build), test (vitest run), preview. Create src/main.tsx wrapping App in BrowserRouter. Create src/App.tsx with Routes for /, /pivot, /ai-native-coding, /about, all pointing at stub page components that render just their route name. Create src/components/Nav.tsx as a sticky/fixed top bar with four NavLink items (Home, Pivot to AI Engineer, AI-Native Coding, About) that apply an active style when the route matches. Create src/components/Footer.tsx with the site name. Create a Layout component that composes Nav + <Outlet/> + Footer. Replace all Vite boilerplate (App.css, logo, index.css content) with a clean Tailwind base layer import. Commit a placeholder src/__tests__/App.test.tsx that imports the app and asserts it renders without crashing — just enough to make `npm test` pass at this phase.

## Phase 2: Phase 2 — All Page Content, Full Visual Design, Responsive Layout, Tests, and README

### What to build

Build out every page and apply the complete visual design. (1) HOME PAGE: Replace the Home stub with a two-section layout. Hero section: full-width, brand-colored background, large bold headline 'Become an AI Engineer', a value-prop subheading (e.g. 'Two focused learning tracks. Real-world skills. Built for engineers.'), and a primary CTA button labeled 'Explore the tracks' that is an anchor link to #tracks — add id='tracks' to the Learning Tracks section so the CSS scroll-behavior: smooth takes it there instantly. Learning Tracks section: two TrackCard components side-by-side on desktop, stacked on mobile, each with a track title, one-line description, and a React Router Link into the track route. (2) TRACK PAGE — PIVOT (/pivot): Title 'Pivot to AI Engineer', intro paragraph describing who it's for, and an ordered/unordered list of 4 module titles: 'Foundations of LLMs', 'Prompt Engineering & Context Design', 'Building RAG Systems', 'Evaluating & Shipping AI Features', each marked 'Coming soon'. (3) TRACK PAGE — AI-NATIVE CODING (/ai-native-coding): Title 'AI-Native Coding', intro paragraph, 4 module titles: 'Coding with AI Assistants', 'Spec-Driven Development', 'Agentic Workflows & Tooling', 'Reviewing AI-Generated Code', each marked 'Coming soon'. (4) ABOUT PAGE (/about): Single-paragraph mission statement — 'everything AI engineering in one place'. No bios. (5) src/data/tracks.ts: export a typed Track[] array with id, label, route, description, and modules fields — TrackCard and the track pages consume this data so adding a track later is one array entry. (6) VISUAL DESIGN: Apply full Tailwind styling throughout — large hero type (text-5xl md:text-6xl font-extrabold text-white), generous vertical padding, brand accent on buttons and active nav links (brand-600 background, hover:brand-700), calm card-based content sections on a white/gray-50 background, consistent inter/system-sans-serif typography, max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 content constraint. Nav: white background, border-b, brand-colored active indicator. Footer: gray-100 background with centered site name. Mobile: hamburger or wrapped nav links, single-column track cards at sm breakpoint. (7) TEST SUITE: Expand src/__tests__/App.test.tsx with all required assertions — hero headline 'Become an AI Engineer' is in the document; a button/link with text 'Explore the tracks' is in the document; the nav contains links/text for all four tabs (Home, Pivot to AI Engineer, AI-Native Coding, About); navigating (via MemoryRouter or render with a specific initialEntries) to /pivot shows the text 'Pivot to AI Engineer'; navigating to /ai-native-coding shows the text 'AI-Native Coding'. (8) README: Replace the one-liner README.md with full documentation covering: prerequisites, npm install, npm run dev (with localhost URL), npm run build, npm test, and a one-paragraph project description.
